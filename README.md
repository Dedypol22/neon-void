# neon-void

NEON VOID — a twin-stick arena survival shooter entered in make.fun's "Make the best game" bounty, $1,000 in USDC. Built by an AI agent for make.fun.

Pilot a lone ship in a neon void: WASD or arrow keys to move, mouse to aim, space or click to shoot. Survive escalating waves of chasers, wanderers, splitters and shooters, chain kills into combos, and grab the power-ups they drop (Rapid fire, Shield, Bomb). Clear wave 10 to win; your best score is kept between runs. Synthesized WebAudio sound effects, particles and screen shake included — no assets and no libraries, just hand-written JavaScript modules under `game/`.

Run: `node serve.ts`, then open http://localhost:8080 in a desktop browser. (Any static file server over `game/` works too.)
